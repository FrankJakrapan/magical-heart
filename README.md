# Magical Heart

หัวใจอนุภาคเรืองแสงแบบ 3 มิติ วาดด้วย Canvas 2D + JavaScript ล้วน ๆ
ไม่มี dependency ไม่มี build step

## ลูกเล่น

- **หมุนได้จริง** — อนุภาคเก็บพิกัดในระบบ 3 มิติ แล้วหมุน + ฉายภาพเองทุกเฟรม เห็นความหนาของหัวใจตอนหมุนผ่านด้านข้าง
- **เส้นแสงลากตาม** — ทุกอนุภาคลากเส้นจากตำแหน่งเฟรมก่อนหน้า ยิ่งเร็วเส้นยิ่งยาว
- **เส้นแสงวิ่งวนรอบ** — สปาร์ก 3 วงโคจรเอียงคนละระนาบ
- **จังหวะแตกตัวแล้วรวมใหม่** — วนอัตโนมัติ: `assemble → idle → burst → reform → idle …`
- **แอ่งแสง + ลำแสง** ใต้หัวใจ พร้อมดาวพื้นหลัง
- รองรับ `prefers-reduced-motion` (ปิดหมุนอัตโนมัติและปิดการระเบิดอัตโนมัติ)

## การควบคุม

| ปุ่ม | ผล |
|---|---|
| คลิก / `Space` | ระเบิดหัวใจทันที |
| ลากเมาส์ | หมุนดูรอบทิศ |
| `A` | เปิด/ปิดหมุนอัตโนมัติ |
| `R` | สร้างอนุภาคใหม่ทั้งหมด |

## รัน

เปิด `index.html` ตรง ๆ ได้เลย หรือถ้าเบราว์เซอร์บล็อกไฟล์ย่อย ให้เสิร์ฟเป็น static:

```bash
python -m http.server 8123
```

แล้วเปิด http://localhost:8123

## โครงสร้าง

```
index.html        โครง + โหลดสคริปต์ตามลำดับ
src/style.css     พื้นหลังดำ, canvas เต็มจอ, HUD
src/heart.js      รูปทรงหัวใจ 3 มิติ (เส้นรอบรูป + สุ่มจุดในเนื้อ + ความหนาตามแกน z)
src/particle.js   ฟิสิกส์อนุภาค (สปริงกลับบ้าน, ระเบิด) + แคชสไปรต์แสง
src/effects.js    ดาว, แอ่งแสง, ลำแสง, สปาร์กวงโคจร
src/main.js       กล้อง/การหมุน, สเตตแมชชีนของจังหวะ, ลูปวาด, อินพุต
```

## ปรับแต่ง

แก้ `CONFIG` ใน `src/main.js`

```js
particles: 1500,        // จำนวนอนุภาค (มือถือลดอัตโนมัติ)
autoSpin: 0.42,         // ความเร็วหมุน (เรเดียน/วินาที)
idleDuration: 6.5,      // นิ่งกี่วินาทีก่อนระเบิดรอบถัดไป
burstDuration: 1.3,
reformDuration: 2.8,
burstPower: 27          // แรงระเบิด
```

- สีอยู่ที่ `PALETTE` ใน `src/particle.js`
- สัดส่วน/ความหนาของหัวใจอยู่ที่ `Y_STRETCH` และ `THICKNESS` ใน `src/heart.js`
- ความยาวหางเส้นคุมด้วยค่าอัลฟาของสี่เหลี่ยมดำที่ทับทุกเฟรมใน `main.js`

## API ในคอนโซล

```js
MagicalHeart.burst();          // สั่งระเบิด
MagicalHeart.rebuild();        // สุ่มอนุภาคใหม่
MagicalHeart.view.autoSpin;    // เปิด/ปิดหมุนอัตโนมัติ
MagicalHeart.phase;            // จังหวะปัจจุบัน
```
