# Magical Heart

หัวใจอนุภาคเรืองแสงแบบ 3 มิติ วาดด้วย Canvas 2D + JavaScript ล้วน ๆ
ไม่มี dependency ไม่มี build step

## ลูกเล่น

- **หัวใจอยู่กับที่ ละอองหมุนวนข้างใน** — หัวใจถูกหั่นเป็นแถบตามความสูง อนุภาคในเนื้อโคจรเป็นวงรีอยู่ในแถบของตัวเอง เงาหัวใจจึงคงรูปเดิมตลอดขณะที่ละอองไหลวน ส่วนอนุภาคขอบจะแกว่งไปมารอบจุดของตัวเองบนเส้นรอบรูป (ไม่วิ่งวนเป็นกรอบ)
- **เส้นแสงลากตาม** — ทุกอนุภาคลากเส้นจากตำแหน่งเฟรมก่อนหน้า ยิ่งเร็วเส้นยิ่งยาว
- **เส้นแสงวิ่งวนรอบ** — สปาร์ก 3 วงโคจรเอียงคนละระนาบ
- **จังหวะแตกตัวแล้วรวมใหม่** — วนอัตโนมัติ: `assemble → idle → burst → reform → idle …` ตอนรวมจะค่อย ๆ บีบกลับแบบเกลียว (เศษยังลอยตามแรงเดิมแล้วเบลนด์เข้าหาบ้านด้วย smootherstep) ไม่ใช่ตัดภาพ
- **โซนล่าง**: แอ่งแสง + ลำแสง + หมอกนอนพื้นและไอที่พวยพุ่งออกด้านข้าง + วงคลื่นแผ่ออก (ตอนระเบิดจะกระชากแรงขึ้น)
- กล้องอยู่นิ่งเป็นค่าเริ่มต้น ลากเมาส์เพื่อหมุนดูรอบทิศ หรือกด `A` เปิดหมุนกล้องอัตโนมัติ
- รองรับ `prefers-reduced-motion` (ปิดหมุนอัตโนมัติและปิดการระเบิดอัตโนมัติ)

## การควบคุม

| ปุ่ม | ผล |
|---|---|
| คลิก / `Space` | ระเบิดหัวใจทันที |
| ลากเมาส์ | หมุนกล้องดูรอบทิศ |
| `A` | เปิด/ปิดหมุนกล้องอัตโนมัติ |
| `R` | สร้างอนุภาคใหม่ทั้งหมด |

## รัน

เปิด `index.html` ตรง ๆ ได้เลย หรือถ้าเบราว์เซอร์บล็อกไฟล์ย่อย ให้เสิร์ฟเป็น static:

```bash
python -m http.server 8123
```

แล้วเปิด http://localhost:8123

## โครงสร้าง

```
index.html        โครง + โหลดสคริปต์ตามลำดับ
src/style.css     พื้นหลังดำ, canvas เต็มจอ, HUD
src/heart.js      โครงหัวใจ 3 มิติ: เส้นรอบรูป + แถบตามความสูง + ที่นั่งที่ไหลวนได้
src/particle.js   ฟิสิกส์อนุภาค (สปริงตาม home, ระเบิด) + แคชสไปรต์แสง/หมอก
src/effects.js    ดาว, แอ่งแสง, ลำแสง, หมอก, วงคลื่น, สปาร์กวงโคจร
src/main.js       กล้อง/การหมุน, สเตตแมชชีนของจังหวะ, ลูปวาด, อินพุต
```

## ปรับแต่ง

แก้ `CONFIG` ใน `src/main.js`

```js
particles: 1500,        // จำนวนอนุภาค (มือถือลดอัตโนมัติ)
mist: 110,              // จำนวนก้อนหมอกโซนล่าง
swirlSpeed: 0.95,       // ความเร็วที่ละอองไหลวนอยู่ในหัวใจ
autoSpin: 0.42,         // ความเร็วหมุนกล้องเมื่อกด A
idleDuration: 6.5,      // นิ่งกี่วินาทีก่อนระเบิดรอบถัดไป
burstDuration: 1.3,
reformDuration: 2.8,
burstPower: 27          // แรงระเบิด
```

- สีอยู่ที่ `PALETTE` ใน `src/particle.js`
- สัดส่วน/ความหนาของหัวใจอยู่ที่ `Y_STRETCH` และ `K` ใน `src/heart.js` (สัดส่วนอนุภาคที่เกาะขอบปรับที่ `randomSeat`)
- ความหนา/ความสว่างของหมอกอยู่ที่ `MistPuff.reset()` ใน `src/effects.js`
- ความยาวหางเส้นคุมด้วยค่าอัลฟาของสี่เหลี่ยมดำที่ทับทุกเฟรมใน `main.js`

## API ในคอนโซล

```js
MagicalHeart.burst();          // สั่งระเบิด
MagicalHeart.rebuild();        // สุ่มอนุภาคใหม่
MagicalHeart.view.autoSpin;    // เปิด/ปิดหมุนอัตโนมัติ
MagicalHeart.phase;            // จังหวะปัจจุบัน
```
